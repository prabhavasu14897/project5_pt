# Memory Grid — Quality Check Skill

Before considering a screen complete, verify the following.

## Visual

- [ ] Matches Stitch design
- [ ] Correct typography
- [ ] Correct spacing
- [ ] Correct colors
- [ ] Correct card dimensions
- [ ] Correct border radius
- [ ] Correct icon sizes
- [ ] Correct visual hierarchy

## Game

- [ ] Cards can be selected
- [ ] Cards flip correctly
- [ ] Matching works
- [ ] Mismatching works
- [ ] Matched cards remain visible
- [ ] Score updates
- [ ] Moves update
- [ ] Timer works
- [ ] Combo works
- [ ] Game completion works
- [ ] Restart works
- [ ] Pause works

## Power-Ups

- [ ] Peek works
- [ ] Freeze works
- [ ] Shuffle works
- [ ] Hint works
- [ ] Used power-ups cannot be incorrectly reused

## Responsive

- [ ] Desktop works
- [ ] Tablet works
- [ ] Mobile works
- [ ] No horizontal overflow
- [ ] Cards remain usable
- [ ] Buttons are touch-friendly

## Accessibility

- [ ] Keyboard navigation works where applicable
- [ ] Focus states are visible
- [ ] Cards have accessible labels
- [ ] Game state is understandable without color alone
- [ ] Reduced motion is respected

## Code Quality

- [ ] No `any`
- [ ] No duplicated game logic
- [ ] No unused imports
- [ ] No console errors
- [ ] No unnecessary dependencies
- [ ] Components are reusable
- [ ] Game logic is testable

## Final Rule

Do not mark a screen complete merely because it looks correct.

It must also behave correctly.
