# Memory Grid — Design System

## Design Direction

Memory Grid should feel:

- Premium
- Modern
- Playful
- Interactive
- Immersive
- Clean
- Gaming-focused

It should NOT feel like:

- A corporate dashboard
- A casino website
- An educational worksheet
- A generic admin panel

## Visual Style

Use a dark gaming interface.

Primary visual characteristics:

- Deep dark background
- Vibrant accent colors
- Soft rounded surfaces
- Subtle gradients
- Controlled glow effects
- Strong contrast
- Large readable typography
- Generous spacing
- Clear hierarchy

## Color Direction

Use the Stitch-approved colors as the source of truth.

Suggested semantic roles:

### Background

Deep navy / near-black.

### Primary

Electric blue.

Used for:

- Primary CTA
- Active controls
- Focus state
- Selected state
- Important interaction

### Secondary

Purple.

Used for:

- Secondary highlights
- Game progression
- Special states

### Success

Green.

Used for:

- Matched cards
- Successful actions
- Victory
- Completed achievements

### Warning

Orange/yellow.

Used for:

- Combo
- Timer warning
- Important game feedback

### Text

Primary:
White / near-white.

Secondary:
Muted blue-gray.

## Typography

Use a modern geometric/sans-serif typeface.

Typography hierarchy:

- Large hero heading
- Clear page heading
- Medium game heading
- Compact metadata
- Highly readable game statistics

Do not use excessively small text.

## Spacing

Use a consistent spacing scale.

Avoid arbitrary spacing values unless required to match the approved Stitch design.

## Radius

Use rounded corners consistently.

Game cards should have a strong but not excessive radius.

## Cards

Cards are the primary visual element.

Card back:

- Dark surface
- Subtle pattern
- Accent detail
- Clear boundaries

Card front:

- Strong visual symbol
- Centered content
- High contrast
- Consistent visual treatment

## Buttons

Primary buttons should be visually prominent.

Examples:

- Play Now
- Start Game
- Play Again
- Next Challenge

Secondary actions should be visually quieter.

## Motion

Animations should feel responsive rather than distracting.

Preferred:

- Card flip
- Button press
- Match feedback
- Combo animation
- Score increment
- Progress animation
- Victory celebration

Respect `prefers-reduced-motion`.

## Visual Fidelity

When implementing Stitch screens:

1. Match layout.
2. Match typography.
3. Match spacing.
4. Match card proportions.
5. Match colors.
6. Match hierarchy.
7. Match interaction states.

Do not replace designed components with generic alternatives.
